Installation Instructions
------------------------------------------------------------------------
Installing system-wide adds the `fount` command to your PATH, installs
the application launcher icon, and sets up desktop menu shortcuts.

1. Open your terminal in the extracted directory.
2. Run the installer with superuser privileges:

       sudo ./install.sh

3. Launch Fount anytime from your application menu or by typing:

       fount

To uninstall in the future, run:

       sudo ./uninstall.sh
