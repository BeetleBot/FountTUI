FOUNT FOR LINUX

Thank you for downloading Fount, the minimal Fountain screenplay editor.

INSTALL (Recommended):
1. Extract the tarball: tar -xzf Fount-Linux-x64-*.tar.gz
2. Run: sudo ./install.sh
3. Launch: fount

PORTABLE (no install):
1. Extract the tarball
2. Grant execution: chmod +x fount
3. Run: ./fount

CONFIGURATION:
Fount stores settings in: ~/.config/fount/fount.conf

SHORTCUTS:
- Ctrl+S: Save
- Ctrl+T: Scene Tree
- Ctrl+L: Character Sidebar
- / (Slash): Open command bar (type /help)

For more information, visit: https://github.com/BeetleBot/Fount
